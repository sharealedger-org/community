Specification Work

The Open Shared-Ledger Protocol

Every existing approach to inter-organizational financial data exchange solves part of the problem and leaves the rest unsolved. Sharealedger is developing the standard that covers both layers.

Layer 1

Shared-Partition Interface

The operations, identifiers, and authorization rules that independent organizations implement to exchange authorized economic event records without disclosing private accounting projections. An implementation satisfying this layer has a shared journal.

Layer 2

Event-to-Position Derivation Contract

The normative rules for correctly deriving participant-specific accounting positions from shared events under declared rules — with a complete, verifiable audit trace from every published position back to its source. An implementation satisfying both layers has a shared ledger.

The gap no existing standard fills. Blockchain and DLT specify the journal layer — they do not specify the posting process or position derivation. ISO 20022 and SWIFT specify message formats — not how those messages are posted or how positions are verified. XBRL and Global Ledger specify report structures — not the computation that produces them. Shared ERP deployments assume a common chart of accounts and a common operator. This specification covers all of it, for independent organizations with different books.
