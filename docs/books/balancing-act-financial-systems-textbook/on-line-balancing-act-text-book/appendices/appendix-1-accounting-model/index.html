Searching for an Open Accounting Model?

Welcome to Sharealedger. If you are looking for an open, event-driven accounting architecture, you have arrived at the organizational home dedicated to modernizing financial systems and ledger definitions.

The Sharealedger Conceptual Model Project

The Sharealedger Conceptual Model is an open-source collaboration to construct an open, mathematically consistent, event-driven financial architecture. It moves beyond the limitations of legacy double-entry silos by unifying transaction capture, low-level balances, and high-performance metric engines.
